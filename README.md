# Three.js Demo Project 2

A simple interactive 3D graphics project built with [Three.js](https://threejs.org/) and [Vite](https://vite.dev/).

This project demonstrates the creation and animation of a 3D dodecahedron alongside a rotating platform, with interactive camera controls powered by OrbitControls.

## Features

- Interactive 3D dodecahedron.
- Continuously rotating 3D objects.
- Realistic lighting using ambient light and spotlight.
- Interactive camera controls using OrbitControls.
- Zooming, panning, and rotating the 3D scene.

## Technologies Used

- JavaScript (ES6+)
- Three.js
- Vite
- WebGL
- HTML5

## Prerequisites

Before running this project, ensure you have the following installed:
